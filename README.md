# :rocket: Projeto Mercado Órbita

Projeto desenvolvido com foco em analisar dados de um e-commerce, com foco em identificar a causa das dores operacionais e propor soluções para melhorar os principais indicadores.

## :dart:  Objetivos
Identificar os fatores que impactam os seguinte indicadores:

- Atraso médio da entrega
- Média de avaliação
- Taxa de clientes recorrentes
Propor recomendações para atingir as metas da empresa.

## :file_folder: Estrutura do Projeto
- `data`: contém todos os dados utilizados no projeto
  - `raw`: datasets originais do Kaggle
  - `interim`: planilhas auxiliares para uso no Power BI
- `notebooks`: arquivos da análise exploratória
- `reports`: resultados da análise e visualizações
  - `dashboard`: imagens e arquivos do Power BI
  - `presentation`: apresentação executiva

## :wrench: Ferramentas e Tecnologias Utilizadas

- Canvas (apresentações)
- Google Colab (analise exploratória)
- Figma (prototipação)
- Notion (planejamento e documentação)
- Power BI (dataviz)
